1) Junho Probe Plate

Problem

AI가 빠르게 만든 결과물이 실행되더라도, 목표와 제약을 왜 정했는지 또는 코드가 어디서 깨지는지를 구현자가 설명하지 못할 수 있습니다.

Decision

기술·의도·인지 증거를 서로 대신할 수 없는 채널로 분리하고, Producer와 독립 Judge가 같은 checkpoint를 병렬 검증하도록 설계했습니다.

Evidence

Project-local skills, Query Wiki, closed-book cognition quiz, deterministic evidence validation을 공개 저장소로 제공합니다.

repository: junho-probe-plate

2) OLIVE BETTER — COFATHON

Problem

올리브영 MD가 공개 웰니스 신호를 상품·카피·화면으로 전환하고 검토·발행·고객 반응 재적용까지 수행하는 흐름을 4시간 안에 구현해야 했습니다.

Decision

AI는 트렌드 해석과 기획 초안을 제안하게 하고, 품절·중복·상품 적격성·문구 안전·발행 여부는 TypeScript 정책과 MD 승인으로 다시 검증했습니다.

Evidence

300개 상품과 12개 필수 흐름을 대상으로 End-to-End MVP를 완성해 Olive Young Track TOP 3, 최종 2위를 기록했습니다.

3) Data Lineage Impact Analysis Agent — SKT AI Fellowship

Problem

ReAct Agent가 데이터 변경 영향도를 찾는 동안 연관 API를 반복 선택하고 불완전한 Context를 누적했습니다.

Decision

질문 해석과 도구 선택은 Agent에 남기고, 호출 순서가 중요한 Upstream·Downstream Lineage 조회는 결정론적 Workflow와 MCP Tool로 분리했습니다.

Evidence

GPT-4o-mini ReAct 대비 Answer Correctness 0.362→0.964, Correct Path Rate 0.536→0.967을 확인했습니다.

public experiment: AI-Fellowship-Demo

4) 든든AI

Problem

중장년 사용자는 숏폼 하나를 만들기 위해 기획·이미지·영상·음성·편집 도구를 각각 배워야 했습니다.

Decision

주제 입력부터 트렌드 탐색, 기획, 나레이션·이미지·영상 생성과 자동 편집을 하나의 Queue 기반 제품 흐름으로 연결하고, 동시 요청 장애 이후 워커를 분리했습니다.

Evidence

50명 조사, 초기 가입자 49명, 첫 영상 발행 82%를 확인했고 GenAI 활용 경진대회 금상과 Y-Startup³ 우수상을 수상했습니다.

5) K-PACK

Problem

한국 화장품 브랜드가 국가마다 다른 패키지 문구·규제·크리에이티브를 병렬로 준비하는 과정을 하나의 Agent 서비스로 줄이고자 했습니다.

Decision

UAE·북미·유럽·일본·중국 현지화를 병렬 실행하되, 규칙 엔진을 기준 결과로 두고 모델은 검증을 통과한 필드만 보강하게 했습니다.

Evidence

5일 안에 5개국 문구·근거 기반 규제 체크·3D 시안·숏폼 키비주얼을 연결해 Wanted AI Championship 2026에 출품했습니다. 결과는 확정 전입니다.

6) ParrotKit

Problem

브랜드의 가이드와 SKU 강점이 크리에이터의 실제 언어·촬영 장면·캠페인 운영으로 자연스럽게 이어지지 않았습니다.

Decision

SKU 이해→보여줄 장면→Hook→크리에이터 경험→고객 행동의 순서로 기획하고, AI는 사람을 대체하지 않고 소구점과 제약을 놓치지 않도록 지원하게 했습니다.

Evidence

뷰티 브랜드 미팅을 통해 TikTok Shop Affiliate의 크리에이터 발굴·소통·게시·성과 흐름을 캠페인 단위 제품으로 구체화했습니다.

repository: parrotkit_app

7) YBIGTA × Glucofit

Problem

7명이 약 60만 건의 식사·혈당 데이터를 세 개 Task로 나눠 다루면서 CSV만으로는 데이터 형식과 결과를 다시 맞추는 통합 비용이 커졌습니다.

Decision

개인정보를 마스킹한 별도 PostgreSQL 개발 DB와 동일 스키마를 제안하고, FastAPI·pgvector로 분석·추천·화면을 통합했습니다.

Evidence

검토했던 CSV 공유 방식 대비 구현 시간을 약 1/3로 줄여 통합 데모를 시연했고 협력사 대표의 앱 반영 의사를 확인했습니다.
